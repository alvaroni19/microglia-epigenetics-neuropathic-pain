# Software versions used to validate release 2.0.0

All result tables and panels were regenerated from the archived inputs with the versions below.

Python 3.11.16: numpy 2.4.6, pandas 2.3.3, scipy 1.17.1, matplotlib 3.11.1, statsmodels 0.15.0,
scikit-learn 1.9.1, seaborn 0.13.2, adjustText 1.4.0, openpyxl 3.1.5, Pillow 12.3.0,
PyMuPDF 1.28.0, logomaker 0.8.7.

R 4.5.3: emmeans, sandwich, lmtest, car, readxl, writexl, dplyr, tidyr, ggplot2, patchwork
(behaviour); FactoMineR, missMDA, vegan (multiple factor analysis); rrcov, ComplexUpset, ragg,
svglite (MeDIP panels).

The MEDIPS notebook was run with R 4.4.2, Bioconductor 3.20 and MEDIPS 1.58.0 (`renv.lock`).
Panels use Arial, which must be installed (the R panel script also accepts ARIAL_FONT_DIR).
